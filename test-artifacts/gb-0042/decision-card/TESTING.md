# 复访判定卡精确求解 — 测试说明

全部测试仅依赖 Python 标准库（无需 numpy / SQLAlchemy / Redis / Docker），
在仓库根目录执行：

```bash
python3 test-artifacts/gb-0042/decision-card/oracle_test.py
python3 test-artifacts/gb-0042/decision-card/perf_test.py
python3 test-artifacts/gb-0042/decision-card/integration_test.py
```

## 测试矩阵

| 文件 | 覆盖口径 |
|---|---|
| `oracle_test.py` | 120 个随机小例（n=6..14，多档误收上限）上**穷举全部深度≤2判定树**，与求解器逐一对照最优命中、误收与同分固定次序；另含同读数同侧、节点少优先、零上限回退、渲染树预测一致性 |
| `perf_test.py` | 2000 站规模：运行时长、每站判断≤2、逐站独立复算一致、六个断点中断/恢复后规则完全相同、重复求解确定性 |
| `integration_test.py` | 内存仓储模拟任务状态机：完整发布闸门、断点恢复、**并发调低误收上限时旧任务 superseded 且旧解永不发布**、复算闸门拦截篡改计数、非法输入拒绝 |

## 口径要点（与业务需求逐条对应）

1. **每站至多判断两次**：规则为深度≤2判定树，`max_judgements_per_station ≤ 2`。
2. **只比较三项原始读数与阈值**：分裂只取 `temperature/humidity/particles` 的实际读数，
   比较符固定为 `x ≤ t` 走左支、`x > t` 走右支。
3. **同读数放同侧**：阈值只取去重后的实际读数，等值读数在同一次扫描中成段进入同一支。
4. **簇外站含噪声都算误收**：目标由 DBSCAN 目标簇标签定义，标签 -1 与其他簇同为非目标。
5. **同分次序**：先判断节点少者，再按字段（温度→湿度→颗粒）、阈值、左支、右支的字典序取首。
6. **精确求解、不枚举完整树、不保存全部候选**：按根分裂枚举（至多 3(n-1) 个），
   每个子集只保留“每个误收数一条最优规则”的压缩前沿，深度2树由两个子集前沿精确合并。
7. **中断恢复已核验范围**：进度以根分裂下标为最小恢复单位，批次边界落盘，
   恢复时从 `index` 继续，已核验范围不重复计算。
8. **并发调低上限旧解不发布**：同 (run, 簇) 新建任务即把旧任务置 `superseded`；
   worker 在批次边界与发布前两次核验任务状态与上限。
9. **逐站复算一致才显示**：`evaluate_rule` 独立于搜索过程重新预测全部站点，
   命中/误收与搜索结果完全一致时才写 `card.verified=true`，前端只渲染已验证卡片。
